# Release Notes: Pure Kinetics Algorithm Release

## Overview

This release introduces the **Pure Kinetics Algorithm**, transitioning breath test analysis to physical gas desorption kinetics ($\tau_{50}$ / $T_{50}$ recovery lag) on the Bosch BME688 MOX gas sensor layer. The system measures real-time surface binding affinity and molecular desorption rates to deliver high-precision breath analysis across hardware, firmware, and the **Votre Air** iOS application.

## Pure Kinetics Algorithm Details

The $T_{50}$ desorption kinetics algorithm evaluates gas desorption kinetics according to the standard physical benchmark ISO 16000-29:

1. **Target Resistance Calculation ($R_{\text{target}50}$)**:

$$R_{\text{target}50} = R_{\text{min}} + 0.5 \times (R_{\text{base}} - R_{\text{min}})$$


* $R_{\text{base}}$: Baseline gas resistance established prior to exhalation.


* $R_{\text{min}}$: Minimum resistance (peak drop) reached during exhalation.




2. **$T_{50}$ Recovery Lag Computation**:

$$T_{50} = t(R_{\text{target}50}) - t(R_{\text{min}})$$


* Calculates the exact time in seconds for the sensor layer to recover $50\%$ back toward ambient baseline.




3. **Molecular Classification**:
* **Fast Desorption ($T_{50} < 4.2\text{s}$)**: Indicates rapidly desorbing, non-sulfur volatile organic compounds (e.g., alcohols, esters).


* **Slow Desorption ($T_{50} \ge 4.2\text{s}$)**: Identifies strongly bound Volatile Sulfur Compounds (VSCs—e.g., $\text{H}_2\text{S}$, $\text{CH}_3\text{SH}$) requiring higher activation energies to break surface bonds.

## Component Release Notes

### 1. Hardware (`/Hardware`)

* **KiCad PCB & Schematics**: Validated micro-heater thermal distribution and gas sampling chamber geometry for stable gas plume exposure and clean air purging.


* **Trace Isolation**: Cleaned up analog sensor line shielding around the BME688 to prevent ground bounce artifacts during active heater cycling.



### 2. Firmware (`/meso_nose_pure_bsec_kinetics`)

* **Sketch**: `meso_nose_pure_bsec_kinetics.ino`

* **Threshold Constants Configured**:
* `BREATH_MIN_SIGNIFICANT_DROP_PCT = 6.0f`

* `BREATH_FRESH_MAX_DROP_PCT = 17.0f`

* `BREATH_SIGNIFICANT_MAX_DROP_PCT = 45.0f`

* `RECOVERY_LAG_MALODOR_THRESHOLD = 4.2f` ($4.2\text{s}$ $T_{50}$ desorption threshold)




* **BSEC Scheduler Safety**: Implemented active profile guards in `setBsecProfile()` to prevent BSEC library deadlocks or timing desynchronization between `millis()` uptime and physical sensor hardware states.


* **Zero Magic Numbers**: Strongly typed constants used for all timing (`_MS`), thresholds (`_PCT`), and hardware settings.



### 3. Mobile App (`/MesoSensorDashBoard` — *Votre Air*)

* **UI & Status Integration**: Integrated single-line dynamic status formatting (e.g., `Pendant (Connected)`, `Pendant (Ready For Pairing)`) and compact action buttons.


* **Watchdog Alignment**: Extended `BMConstants.blowWindowTimeoutSeconds` to `32.0s` ($30\text{s}$ firmware blow window $+ 2\text{s}$ BLE transmission buffer).


* **Teardown Parity**: Aligned `handleBreathTestCompletion(didSucceed: Bool, failureReason: String? = nil)` to handle timeout and weak exhalation telemetry events safely.


* **Result Card Highlight**: Added a 3-second scale animation ($+3\%$) with a green glow overlay on `VotreAirDashboardView` when completing a successful breath analysis test.


* **Sensor Baseline Floor Guard**: `transientWarmupVocFloor = 1000 Ohms` ensures valid ambient readings prior to transitioning state to `.idle`.
